# WEBTAGONS Indonesia — Company Profile & Digital Portfolio

Website company profile dan digital portfolio untuk **WEBTAGONS Indonesia**, dibangun di atas framework Next.js, Three.js, Tailwind CSS, dan Framer Motion.

## Layanan Utama
1. **01. Website Development** — Pengembangan website profesional untuk perusahaan, lembaga, organisasi, dan bisnis dengan desain responsif serta pengalaman pengguna yang optimal.
2. **02. Custom Web Application** — Pengembangan aplikasi berbasis web yang dirancang sesuai kebutuhan operasional, proses bisnis, dan sistem kerja organisasi.
3. **03. Company Profile Website** — Website profil perusahaan untuk memperkuat identitas digital, meningkatkan kredibilitas, dan memperkenalkan produk maupun layanan.
4. **04. Online Voting System** — Sistem pemungutan suara digital dengan manajemen peserta, verifikasi pemilih, rekapitulasi suara, dan dashboard monitoring.
5. **05. Learning Management System** — Platform pembelajaran digital untuk mengelola kelas, materi, tugas, ujian online, nilai, dan perkembangan peserta.
6. **06. Digital Platform & Information System** — Pengembangan platform digital dan sistem informasi untuk membantu pengelolaan data, administrasi, serta layanan berbasis teknologi.

## Menjalankan Project

### Development
```bash
npm run dev
# atau
pnpm dev
```
Buka browser di: [http://localhost:3000](http://localhost:3000)

### Production Build
```bash
npm run build
npm start
```
